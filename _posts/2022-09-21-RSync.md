# RSync command

## Sync local folder to the server

```bash
rsync -tru --delete --info=progress2 ~/projects/MDPPricing  mf:/home/mrkos/projects/MDPPricing
```

```bash
rsync -tru --delete --info=progress2 ~/projects/MDPPricing  mf:/home/mrkos/projects/MDPPricing
```

copies from SOURCE to DESTINATION with

- `--delete` deletes files in DESTINATION that are no longer present in SOURCE
- `-t` timestamps are kept during transfer
- `-r` recursively copy folders
- `-u` update only changed file
- `--info=progress2` displays progress bar

### Important when syncing directories:

- `rsync /source/dir ~/local` puts **directory** `dir` into directory `local` 
- `rsync /source/dir/ ~/local` puts **contents** of `dir` into `local`

Here, `local` or `local/` does not matter.


## Sync from server to folder
```bash 
rsync -havzP --info=progress2 mf:/home/mrkos/projects/MDPPricing ~/projects
```

## If sending files list takes a long time

Check you are not using the -c flag that calculates checksum for all files *before* sending the files. This takes a lot of time and likely is not usually needed.

## Exclude certain extensions in zsh

Use [e.g.](https://stackoverflow.com/a/38124804/1400490):
```bash
--exclude='*'.{bak,save,backup,old}
```
