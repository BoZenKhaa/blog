# Looking for code inefficiencies in PMDPs.jl

## Using Profiler

Profiler can be used as

```Julia
using Profile
Profile.clear()
@profview POMDPs.action(planner, s₀)
```

Using Profiler, I got to see some weird array allocations, which lead to discovery of following inefficiencies:

### Broadcast allocated array

In `isterminal` method, I used to have a following check:

```Julia
all(rand(10) .< 0)
```

This inadvertantly allocates whole new bit-array each time, which is slow. The speedup:

| ID                                       | time ratio                   | memory ratio                 |
|------------------------------------------|------------------------------|------------------------------|
| `["generative_ev-mcts", "action_large"]` | 0.83 (5%) :white_check_mark: | 0.52 (1%) :white_check_mark: |
| `["generative_ev-mcts", "action_tiny"]`  | 0.78 (5%) :white_check_mark: | 0.81 (1%) :white_check_mark: |

Notably, I could try to remove the check alltogether and put `isterminal` boolean flag into state.

Similar thing was happening in `sale_imposible`, replacing the broadcast `any(0 .> c-p)` with generator `any(vc-vp < 0 for (vc,vp) in zip(c,p))` provided following speedup: 

| ID                                       | time ratio                   | memory ratio                 |
|------------------------------------------|------------------------------|------------------------------|
| `["generative_ev-mcts", "action_large"]` | 0.87 (5%) :white_check_mark: | 0.48 (1%) :white_check_mark: |
| `["generative_ev-mcts", "action_tiny"]`  | 0.93 (5%) :white_check_mark: | 0.83 (1%) :white_check_mark: |

### Use view instead of new array when getting the reject action

I was creating new array in POMDPs.actions:

```Julia
if sale_impossible(m, s)
        return [actions[1]]
```

This is just dumb, by replacing the array creation with a view (`view(actions,1)`), I got following speedup:
| ID                                       | time ratio                   | memory ratio                 |
|------------------------------------------|------------------------------|------------------------------|
| `["generative_ev-mcts", "action_large"]` | 0.88 (5%) :white_check_mark: | 0.81 (1%) :white_check_mark: |
| `["generative_ev-mcts", "action_tiny"]`  |                   0.95 (5%)  | 0.95 (1%) :white_check_mark: |
