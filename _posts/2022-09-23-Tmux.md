# Tmux

## Command line controls

### Start a named session

```bash
$ tmux new -s jupyter
```

### List sessions

```bash
$ tmux ls
```

### Attach to a session

```bash
tmux attach-session -t jupyter
```

### Kill session

```bash
$ tmux kill-session -t julia_vscode
```

### Tmux controls

Modifier: `C-b` (Control+b)

Window controls

- `C-b c` - create new window
- `C-b N` or `P` - next and previous window
- `C-b ,` - rename window
- `C-b W` - list windows

Session controls

- `C-b d` - detach
- `C-b x` - kill
- `C-b s` - show and jump between running sessions
- `C-b $` - rename session

Pane (split screen) controls

- `C-b "` - horizontal split
- `C-b %` - vertical split
- `C-b ⬆`, `⬇`, `⬅`, `➡`, `hjkl` - move between panes in current window
- `C-b q` - show pane number
- `C-b o` - move between panes in order
- `C-b {`, `}` - move panes around

### Settings

[Enable mouse scroll](https://superuser.com/a/510310) by creating a tmux config file `~/.tmux.conf`:
```bash 
set -g mouse on        #For tmux version 2.1 and up
```
